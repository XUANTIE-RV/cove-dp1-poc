# Changelog

## 0.3.0

- Vendor the kvmtool sources into the repository, now cross-compiled into
  `lkvm-static` through the unified `./build.sh lkvm` entry.
- Add provenance, licensing and downstream modification notices for kvmtool,
  completing open-source traceability and compliance information.

## 0.2.0

- Initial open-source release of the CoVE DP-1 PoC: a QEMU-based RISC-V (RV64GC)
  demo environment featuring the TSM (TEE Security Manager) reference
  implementation and the unified `build.sh` entry script.
